# Ответственный по институту — API для фронта

Базовый префикс: `/api/teams/institute-responsible/`

**Доступ:** роли `institute_validator`, `admin`, `cpds` (и `is_staff`).
**Авторизация:** `Authorization: Bearer <token>`
**Формат полей:** camelCase.

Институт для `institute_validator` определяется автоматически по подразделению пользователя. Для `admin` / `cpds` обычно нужен query-параметр `institute_code`.

Наставники привязаны к группе **в рамках семестра** (модель `StudyGroupSemester`, M2M `mentors`). У группы может быть несколько наставников. POST добавляет наставника в список, DELETE снимает конкретного.

---

## Общие query-параметры

| Параметр | Обязательный | Описание |
|----------|--------------|----------|
| `semester_id` | да* | ID семестра, `actual` или `next` |
| `institute_code` | нет** | Код института (например `INST-1`) |

\* Не нужен только для `GET /employees/`.

\** Для `institute_validator` с одним институтом можно не передавать. Для `admin` / `cpds` — обязателен. Если у validator доступ к нескольким институтам — тоже обязателен.

### Значения `semester_id`

| Значение | Описание |
|----------|----------|
| `actual` | Текущий активный семестр (`Settings.active_semester_code`) |
| `next` | Следующий семестр (`Settings.next_semester_code`) |
| `42` | Числовой ID семестра |

## 1. Список активных групп института

```http
GET /api/teams/institute-responsible/groups/?semester_id=actual
```

Возвращает учебные группы института с `is_end = false`. Параметр `semester_id` обязателен (валидация семестра); состав списка от треков не зависит — только активные группы института.

### Ответ `200`

```json
[
  {
    "id": 1,
    "name": "ИВТ-101",
    "courseNumber": 3,
    "directionCode": "09.03.01"
  },
  {
    "id": 2,
    "name": "ИВТ-102",
    "courseNumber": 3,
    "directionCode": "09.03.01"
  }
]
```

| Поле | Описание |
|------|----------|
| `id` | ID учебной группы |
| `name` | Название группы |
| `courseNumber` | Номер курса |
| `directionCode` | Код направления подготовки |

### Ошибки

| Код | Когда |
|-----|--------|
| `401` | Нет авторизации |
| `403` | Недостаточно прав |
| `400` | Не передан / некорректный `semester_id` |

## 2. Сотрудники института

```http
GET /api/teams/institute-responsible/employees/
GET /api/teams/institute-responsible/employees/?institute_code=INST-1
```

Список сотрудников института для выбора наставника в UI (и других справочников). Возвращаются пользователи из дерева подразделений института.

**Не включаются:** студенты (`student`), администраторы (`admin`), `is_staff`.

### Ответ `200`

```json
[
  {
    "id": 42,
    "fullName": "Иванов Иван Иванович"
  },
  {
    "id": 57,
    "fullName": "Петров Пётр Сергеевич"
  }
]
```

| Поле | Описание |
|------|----------|
| `id` | ID пользователя |
| `fullName` | ФИО (`get_full_name`) |

Список отсортирован по фамилии, имени.

### Ошибки

| Код | Когда |
|-----|--------|
| `401` | Нет авторизации |
| `403` | Недостаточно прав / нет доступных институтов |
| `400` | Для admin/cpds не передан `institute_code` |

## 3. Группы с назначенными наставниками

```http
GET /api/teams/institute-responsible/group-mentors/?semester_id=actual
```

Один запрос для экрана «распределение наставников»: список групп, у каждой — массив `mentorIds`. ФИО наставников берите из `GET /employees/` по id.

### Ответ `200`

```json
[
  {
    "id": 1,
    "name": "ИВТ-101",
    "courseNumber": 3,
    "directionCode": "09.03.01",
    "mentorIds": [42, 57]
  },
  {
    "id": 2,
    "name": "ИВТ-102",
    "courseNumber": 3,
    "directionCode": "09.03.01",
    "mentorIds": []
  }
]
```

| Поле | Описание |
|------|----------|
| `id` | ID учебной группы |
| `name` | Название группы |
| `courseNumber` | Номер курса |
| `directionCode` | Код направления |
| `mentorIds` | Массив ID назначенных наставников (может быть пустым) |

### Ошибки

| Код | Когда |
|-----|--------|
| `401` | Нет авторизации |
| `403` | Недостаточно прав |
| `400` | Не передан / некорректный `semester_id` |

## 4. Назначить наставника группе

```http
POST /api/teams/institute-responsible/groups/{groupId}/mentor/?semester_id=actual
Content-Type: application/json

{
  "mentorId": 42
}
```

**Добавляет** наставника к группе в указанном семестре (не заменяет существующих). Повторное назначение того же наставника идемпотентно.

### Тело запроса

| Поле | Тип | Описание |
|------|-----|----------|
| `mentorId` | `number` | ID сотрудника института (любая роль, кроме `student`; см. `GET /employees/`) |

### Ответ `200`

```json
{
  "groupId": 1,
  "semesterId": 5,
  "mentorIds": [42, 57]
}
```

### Ошибки

| Код | Типичное сообщение | Когда |
|-----|-------------------|--------|
| `400` | `Сотрудник с id=… не найден в институте` | Чужой / несуществующий пользователь / студент |
| `400` | `Учебная группа завершила обучение` | `is_end = true` |
| `400` | `Учебная группа не принадлежит указанному институту` | Группа другого института |
| `400` | `Учебная группа с id=… не найдена` | Неверный `groupId` |
| `403` | Недостаточно прав | Нет доступа к институту |
| `401` | — | Нет авторизации |

Формат ошибки:

```json
{
  "error": "Текст для пользователя"
}
```

Ошибки валидации тела (`mentorId` отсутствует / не число) — `400` в стандартном формате DRF.

## 5. Снять наставника с группы

```http
DELETE /api/teams/institute-responsible/groups/{groupId}/mentor/?semester_id=actual&mentor_id=42
```

Снимает **конкретного** наставника с группы в указанном семестре. Повторный вызов безопасен.

| Параметр | Обязательный | Описание |
|----------|--------------|----------|
| `mentor_id` | да | ID наставника для снятия |

### Ответ `200`

```json
{
  "groupId": 1,
  "semesterId": 5,
  "mentorIds": [57]
}
```

### Ошибки

| Код | Когда |
|-----|--------|
| `400` | Не передан `mentor_id` |
| `400` | Остальные ошибки как у POST (группа, институт, сотрудник) |

## Рекомендуемый UX

1. **Инициализация экрана** — выбранный семестр (селектор или `semester_id=actual`).
2. **Загрузка данных** — параллельно:
   - `GET /group-mentors/?semester_id=…` — таблица групп с `mentorIds`;
   - `GET /employees/` — справочник ФИО по `id` для селекта и отображения.
3. **Только список групп** (без наставников) — `GET /groups/?semester_id=…`.
4. **Назначение** — `POST …/groups/{id}/mentor/?semester_id=…` с `{ "mentorId": N }`, обновить `mentorIds` из ответа.
5. **Снятие** — `DELETE …/groups/{id}/mentor/?semester_id=…&mentor_id=N`.
6. Группы с пустым `mentorIds` — «наставники не назначены».

### Справочник сотрудников для отображения ФИО

```typescript
const employeesById = Object.fromEntries(
  employees.map((employee) => [employee.id, employee.fullName])
);

const rows = groups.map((group) => ({
  ...group,
  mentorNames: group.mentorIds.map(
    (id) => employeesById[id] ?? "—"
  ),
}));
```

## Связь со студенческим API

Студент видит наставника в «Моей группе»:

```http
GET /api/teams/study-groups/my/?semester_id=actual
```

Если передан `semester_id`, наставники возвращаются в массиве `mentors` из назначения ответственного (`StudyGroupSemester`). Без `semester_id` — fallback на legacy-поле `StudyGroup.mentor` (один элемент в `mentors`, если заполнено).

После назначения наставников ответственным студент увидит их в карточке группы при том же `semester_id`.

## Права и область видимости

| Роль | Группы / наставники | Сотрудники |
|------|---------------------|------------|
| `institute_validator` | Только свой институт | Только свой институт |
| `admin` / `cpds` | По `institute_code` | По `institute_code` |
| `student` и др. | `403` | `403` |

## Отличие от project-tracks

Похожий список групп есть в:

```http
GET /api/showcase/project-tracks/groups/?semester_id=actual&institute_code=…
```

Тот endpoint заточен под **распределение проектов** (поле `assignedProjectsCount`). Для экрана **назначения наставников** используйте `/api/teams/institute-responsible/`.
