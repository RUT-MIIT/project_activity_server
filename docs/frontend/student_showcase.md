# Витрина проектов (студент) — API для фронта

Базовый префикс: `/api/showcase/student-showcase/`

**Доступ:** только роль `student` с привязанной учебной группой.
**Авторизация:** `Authorization: Bearer <token>`
**Формат полей:** camelCase.

Группа студента берётся с бэка (`user.study_group`) — передавать `group_id` не нужно.

Опциональный query-параметр всех методов:

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `semester_id` | `number` \| `"actual"` \| `"next"` | `"actual"` | Семестр |

---

## 1. Список треков с проектами

```http
GET /api/showcase/student-showcase/?semester_id=actual
```

Возвращает проектные треки **учебной группы** текущего студента. В каждом треке — список одобренных проектов.

### Ответ `200`

```json
[
  {
    "id": 1,
    "name": "Трек 1",
    "description": "Описание трека",
    "projects": [
      {
        "id": 10,
        "title": "Название проекта",
        "company": "ООО Заказчик",
        "maxTeams": 3,
        "enrolledTeamsCount": 1,
        "minTeamMembers": 4,
        "maxTeamMembers": 7,
        "isContinuing": false,
        "isCompetitiveSelection": false,
        "tags": [
          { "id": 1, "name": "AI", "category": "Tech" }
        ]
      }
    ]
  }
]
```

| Поле | Описание |
|------|----------|
| `maxTeams` | Максимум команд на проект |
| `enrolledTeamsCount` | Сколько команд уже записалось |
| `minTeamMembers` / `maxTeamMembers` | Лимиты размера команды для проекта |
| `isContinuing` | Продолжающийся проект |
| `isCompetitiveSelection` | В проекте есть конкурсный отбор |
| `tags` | Теги проекта |

**Заголовок ответа:** `Cache-Control: private, max-age=30`

### Ошибки

| Код | Когда |
|-----|--------|
| `403` | Не студент / нет учебной группы |
| `400` | Некорректный `semester_id` |

## 2. Детали проекта

```http
GET /api/showcase/student-showcase/projects/{projectId}/?semester_id=actual
```

Проект доступен, только если он в треке группы студента. Иначе `404` (чужие проекты не раскрываются).

Контакты заказчика и автора **не отдаются**.

### Ответ `200`

```json
{
  "id": 10,
  "title": "Название проекта",
  "company": "ООО Заказчик",
  "goal": "Цель",
  "barrier": "Барьер",
  "existingSolutions": "Существующие решения",
  "context": "Контекст проекта",
  "projectLevel": "L1",
  "tags": [
    { "id": 1, "name": "AI", "category": "Tech" }
  ],
  "maxTeams": 3,
  "enrolledTeamsCount": 1,
  "minTeamMembers": 4,
  "maxTeamMembers": 7,
  "isContinuing": false,
  "isCompetitiveSelection": false,
  "trackId": 1,
  "canEnroll": true
}
```

| Поле | Описание |
|------|----------|
| `company` | Организация-заказчик |
| `projectLevel` | Направление / уровень проекта |
| `trackId` | Трек, к которому привязан проект |
| `canEnroll` | Можно ли **текущему** пользователю записать команду прямо сейчас |

`canEnroll === true`, только если:
- пользователь — капитан команды в семестре;
- статус команды `assembled` (состав подтверждён);
- команда ещё не записана на проект;
- проект в треке команды;
- число участников в `[minTeamMembers, maxTeamMembers]`;
- есть свободный слот (`enrolledTeamsCount < maxTeams`).

**Заголовок ответа:** `Cache-Control: private, max-age=30`

### Ошибки

| Код | Когда |
|-----|--------|
| `404` | Проект не найден / недоступен группе |
| `403` | Нет прав студента |

## 3. Записать команду на проект

```http
POST /api/showcase/student-showcase/projects/{projectId}/enroll/?semester_id=actual
```

Body не нужен. Проект берётся из URL.

Доступно **только капитану** при статусе команды `assembled`.

### Ответ `200`

```json
{
  "teamSemesterId": 55,
  "projectId": 10,
  "projectTitle": "Название проекта"
}
```

После успеха:
- у команды проставляется проект (смена проекта запрещена);
- в лог команды пишется событие записи.

### Ошибки

| Код | Типичное сообщение | Когда |
|-----|--------------------|--------|
| `403` | Действие доступно только капитану | Не капитан |
| `400` | Вы не состоите в команде… | Нет команды в семестре |
| `400` | …после подтверждения состава… | Статус не `assembled` |
| `400` | Команда уже записана на проект | Повторная запись |
| `400` | Проект не найден в треке… | Проект не из трека команды |
| `400` | Число участников… в пределах X–Y… | Размер команды не подходит |
| `400` | …максимальное число команд | Квота слотов исчерпана |

Формат ошибки:

```json
{ "error": "Текст для пользователя" }
```

## Рекомендуемый UX

1. **Список витрины** — `GET /` → аккордеон/табы по трекам, карточки проектов.
2. **Карточка** — показать `title`, `company`, слоты `enrolledTeamsCount / maxTeams`, min/max участников, теги.
3. **Детали** — `GET /projects/{id}/` → поля goal / barrier / existingSolutions / context / projectLevel.
4. **Кнопка «Записаться»**:
   - показывать активной только если `canEnroll === true`;
   - иначе disabled + подсказка (не капитан / состав не подтверждён / уже записаны / нет мест / не тот трек).
5. После успешного `enroll` — обновить детали проекта и/или «Мою команду» (`/api/teams/my-team/`).

### Слоты на карточке

```
занято: enrolledTeamsCount
всего:  maxTeams
свободно: maxTeams - enrolledTeamsCount
```

Если `enrolledTeamsCount >= maxTeams` — запись недоступна.

## Связь с другими студенческими API

| Раздел | API |
|--------|-----|
| Формирование команд | `/api/teams/lobby/` |
| Подтверждение состава | `POST /api/teams/my-team/confirm-composition/` → статус `assembled` |
| Моя команда | `/api/teams/my-team/` |
| Витрина | `/api/showcase/student-showcase/` |

Порядок для студента: собрать команду → подтвердить состав → выбрать проект на витрине.
