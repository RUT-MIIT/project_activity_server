# Приглашение в команду по трекам группы — API для фронта

Базовый префикс: `/api/teams/my-team/`

**Доступ:** студент с учебной группой; поиск и отправка приглашений — только капитану команды в статусе `forming`.

**Авторизация:** `Authorization: Bearer <token>`
**Формат полей ответа:** camelCase.

---

## Что изменилось (вариант C)

- Команда может создаваться **без** `track_id`, если у учебной группы несколько треков (трек проставится при записи на проект).
- Если у группы ровно один трек — он подставляется автоматически.
- Поиск/приглашение: студенты из **всех групп всех треков** учебной группы капитана (`scope: "group_tracks"`).
- `canCreateTeam` не смотрит слоты `recommendedTeamsCount` трека (временно отключено).
- `tracks[].teamsCount` остаётся информативным.
- В лобби список команд по-прежнему только своей группы.

## Создание команды

```http
POST /api/teams/lobby/teams/
{ "name": "Команда", "track_id": null }
```

| Ситуация | Поведение |
|----------|-----------|
| Один трек у группы, `track_id` не передан | Трек проставляется сам |
| Несколько треков, `track_id` не передан | `project_track = null` |
| `track_id` передан | Проверяется доступность группе |

## Поиск кандидатов

```http
GET /api/teams/my-team/invite-candidates/?q=Ива&limit=20&semester_id=actual
```

### Query-параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `q` | `string` | да | Кусок ФИО; токены через пробел, каждый ≥ 2 символов (регистр не важен, в т.ч. кириллица) |
| `limit` | `number` | нет | Лимит результатов (по умолчанию 20, максимум 50) |
| `semester_id` | `number` \| `"actual"` \| `"next"` | нет | Семестр (по умолчанию `actual`) |

### Ответ `200`

```json
{
  "trackId": null,
  "scope": "group_tracks",
  "results": [
    {
      "id": 120,
      "user_id": 34,
      "full_name": "Иванов Иван Иванович",
      "group": { "id": 3, "name": "УВП-211" },
      "isRegistered": true,
      "inTeam": false,
      "team": null,
      "hasPendingInvitation": false,
      "canInvite": true
    }
  ]
}
```

| Поле | Описание |
|------|----------|
| `trackId` | Трек команды или `null` до записи на проект |
| `scope` | `"group_tracks"` — union групп всех треков учебной группы |
| `canInvite` | Можно ли отправить приглашение сейчас |

Пригласить можно только если `canInvite === true` (нужен `user_id`).

### Ошибки

| Статус | Когда |
|--------|-------|
| `400` | Короткий `q`, нет команды, состав уже подтверждён |
| `403` | Не капитан / не студент |

## Отправка приглашения

```http
POST /api/teams/my-team/invitations/
Content-Type: application/json

{
  "user_id": 34,
  "role": "member"
}
```

Сценарий: поиск → выбор с `canInvite: true` → `POST /invitations/` → принятие через лобби.

Pending-приглашения **других** команд не мешают. Блокирует только pending **вашей** команды или уже состоящий в команде студент.
