# Импорт учебных групп из Excel

Пайплайн для загрузки учебных групп любого института из отчёта контингента 1С.

## Общая схема

```text
отчёт 1С (.xls / .xlsx)
        │
        ▼
scripts/prepare_study_groups_xlsx.py
        │
        ▼
файл *_аббр.xlsx  (листы students + groups)
        │
        ▼
manage.py import_study_groups_from_xlsx --institute CODE
        │
        ▼
StudyGroup в БД (institute = CODE)
```

## 1. Подготовка файла

Скрипт: `scripts/prepare_study_groups_xlsx.py`

Читает отчёт контингента (маркеры `Группа : XXX(...)` и строки студентов), добавляет аббревиатуру и год приёма, сохраняет два листа.

```bash
venv\Scripts\activate
python scripts/prepare_study_groups_xlsx.py ^
  --input data/ВИШ_01_09.xls ^
  --output data/ВИШ_01_09_аббр.xlsx
```

Для `.xls` нужен пакет `xlrd` (уже в `requirements.txt`).

### Лист `students`

| Колонка | Описание |
|---------|----------|
| ФИО (полное) | ФИО студента |
| Специальность | Специальность из отчёта |
| Кафедра | Кафедра |
| Профиль/специализация/программа | Профиль |
| Форма обучения | очная / заочная / … |
| Курс | Номер курса |
| Код специальности | Например `09.03.01` |
| Направление специальности | Текст направления |
| Дата планового окончания | Дата |
| СНИЛС | СНИЛС |
| ID_student | ID из 1С |
| Аббревеатура группа | Из маркера `Группа : ШЭТ-411(...)` → `ШЭТ-411` |
| Год приема | `year(дата окончания) − курс` (справочно) |

### Лист `groups`

Уникальные комбинации полей группы (именно этот лист читает команда импорта).

| № (iloc) | Колонка | Использование при импорте |
|----------|---------|---------------------------|
| 0 | Специальность | не используется |
| 1 | Профиль/специализация/программа | имя направления (если создаём новое) |
| 2 | Форма обучения | не используется |
| 3 | Курс | `course_number` |
| 4 | Код специальности | FK `Direction.code` |
| 5 | Дата планового окончания | не используется |
| 6 | Аббревеатура группа | `StudyGroup.code` и `name` |
| 7 | Год приема | не используется (год считается заново) |

Порядок колонок важен: парсер читает по позиции (`iloc`), а не по имени.

## 2. Импорт в БД

Команда: `import_study_groups_from_xlsx`

```bash
venv\Scripts\activate
python manage.py import_study_groups_from_xlsx ^
  --file data/ВИШ_01_09_аббр.xlsx ^
  --institute VISH ^
  --clear ^
  --base-year 2027
```

### Обязательные аргументы

| Аргумент | Описание |
|----------|----------|
| `--file` | Путь к `*_аббр.xlsx` |
| `--institute` | Код института (`Institute.code`): `IEF`, `VISH`, `ITTSY`, … |

Институт должен уже существовать (`python manage.py import_institutes`).

### Опциональные аргументы

| Аргумент | По умолчанию | Описание |
|----------|--------------|----------|
| `--sheet` | `groups` | Имя листа |
| `--clear` | выкл. | Удалить **только** группы этого института перед импортом |
| `--base-year` | `2027` | База для расчёта года набора |

### Примеры для разных институтов

```bash
python manage.py import_study_groups_from_xlsx --file data/ИЭФ_01_09_аббр.xlsx --institute IEF --clear --base-year 2027
python manage.py import_study_groups_from_xlsx --file data/ВИШ_01_09_аббр.xlsx --institute VISH --clear --base-year 2027
```

`--clear` затрагивает только указанный `--institute`, группы других институтов не трогает.

## 3. Правила импорта

### Год набора

```text
enrollment_year = base_year − course_number
```

При `--base-year 2027`:

- 1 курс → 2026
- 2 курс → 2025
- 3 курс → 2024
- 4 курс → 2023

Колонка «Год приема» в Excel **не** используется командой импорта (она нужна для справки на листе students/groups).

### Фильтры (строки пропускаются)

1. **Магистратура** — код направления вида `**.04.**` (например `38.04.01`) — все курсы.
2. **Бакалавриат 1 курса** — код `**.03.**` и `курс == 1`.

Специалитет (`**.05.**`) и прочие уровни импортируются без этих ограничений.

### Идемпотентность

Ключ уникальности: `(institute, code)`.

Повторный запуск обновляет существующие группы (`update_or_create`). Если в листе `groups` одна аббревиатура встречается несколько раз (разные профили/годы), побеждает последняя строка.

### Направления

Если `Direction` с кодом из колонки «Код специальности» нет, он создаётся автоматически:

- `code` — код из Excel
- `name` — из колонки «Профиль/специализация/программа»
- `level` — по умолчанию бакалавриат

### Поля StudyGroup

| Поле | Источник |
|------|----------|
| `institute` | `--institute` |
| `code`, `name` | аббревиатура группы |
| `course_number` | курс |
| `direction` | код специальности |
| `enrollment_year` | `base_year − курс` |
| `is_end` | всегда `False` |
