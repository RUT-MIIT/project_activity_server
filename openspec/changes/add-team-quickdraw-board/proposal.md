# Proposal

## Why

Quickdraw синхронизирует рисунки только между вкладками одного браузера. Команде нужна общая доска, которую можно открыть на другом устройстве и восстановить после переподключения.

## What Changes

- Добавить одну сохранённую доску на `TeamSemester` и REST API для загрузки и полной перезаписи snapshot.
- Добавить комнату WebSocket для участников этой команды и передачу живых правок без эха отправителю.
- Подготовить ASGI, Redis и проксирование `/ws/` для серверного деплоя.
- Описать контракт для отдельной интеграции в `project_activity_client`.

## Capabilities

### New Capabilities

- `team-quickdraw-board`: доступ участников к общему snapshot и живым правкам команды.

### Modified Capabilities

## Impact

Затрагивает приложение `teams`, миграции, ASGI и конфигурацию деплоя. Контракт REST добавляется под `/api/teams/`. История, CRDT, курсоры, лазер и отдельное API для изображений вне объёма изменения.
