# Proposal

## Why

Составителям треков и администраторам нужно быстро видеть, у каких заявок семестра заполнен «Комментарий для составителя трека», а у каких — пустой или заглушка. Сейчас поле есть в карточке заявки и в API, но массовой выгрузки из админки нет — приходится просматривать заявки по одной.

## What Changes

- Добавить Django admin action на списке `ProjectApplication`: выгрузка выбранных заявок в Excel (xlsx).
- Файл содержит два листа с одинаковыми колонками: «Автор заявки», «Институт» (корневое подразделение автора), «Название заявки», «Комментарий составителю трека».
- Первый лист — заявки с нормально заполненным комментарием; второй — с пустым или «условно пустым» (placeholder вроде `-`, `нет`, `n/a`).
- Выборка — отмеченные в changelist заявки после фильтра по семестру; при смешанных семестрах или пустой выборке — отказ с сообщением.
- Публичный API и контракты showcase **не меняются**.

## Capabilities

### New Capabilities

- `admin-track-composer-comment-excel`: Excel-выгрузка комментариев составителю трека из админки заявок (два листа, институт автора через корневое подразделение, правила «условно пустых»).

### Modified Capabilities

- (нет)

## Impact

- `showcase/admin.py` — admin action + ответ с xlsx.
- Новый domain-модуль формирования Excel (по образцу `teams/domain/institute_students_excel.py`), с разбиением по заполненности комментария и резолвом института через `get_root_department(author.department)`.
- Тесты: unit на классификацию комментария / строки / workbook; интеграционный на admin action.
- Зависимость: уже используемый `openpyxl`. Внешних сервисов нет.
