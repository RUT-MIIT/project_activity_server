# Proposal

## Why

ИЭФ нужны специальные теги из предоставленного документа. Существующая команда импорта полностью удаляет справочник и связи с заявками, поэтому не подходит для добавления тегов института.

## What Changes

- Сохранить исходный документ «Хэштеги для ИЭФ.docx» в проекте и добавить отдельную команду импорта его тегов.
- Импортировать названия без начального `#`, используя заголовки разделов как категории и связывая теги с подразделением ИЭФ.
- Обеспечить безопасный повторный запуск без удаления существующих тегов и связей.

## Capabilities

### New Capabilities

- `ief-special-tags-import`: импорт специальных тегов ИЭФ из поставленного документа.

### Modified Capabilities

Нет.

## Impact

Документ в репозитории, Django management command и её тесты; используется существующая модель Tag и подразделение института IEF. Публичные API не изменяются.
