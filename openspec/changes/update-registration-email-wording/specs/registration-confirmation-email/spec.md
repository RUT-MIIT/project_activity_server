# Spec Delta

## Purpose

Письмо подтверждает успешную самостоятельную регистрацию по предрегистрации и содержит данные для входа на портал.

## ADDED Requirements

### Requirement: Письмо об успешной самостоятельной регистрации
После успешной самостоятельной регистрации по предрегистрации система SHALL отправлять письмо с темой «Регистрация завершена», адресом портала, логином и паролем, введёнными пользователем при регистрации. Письмо MUST NOT рекомендовать сменить пароль после первого входа.

#### Scenario: Регистрация пользователя по предрегистрации
- **WHEN** пользователь успешно регистрируется, указав логин и пароль
- **THEN** письмо содержит тему «Регистрация завершена», адрес портала, указанные логин и пароль и не содержит рекомендации сменить пароль после первого входа
