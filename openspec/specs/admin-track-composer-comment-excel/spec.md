# admin-track-composer-comment-excel Specification

## Purpose

Описывает Excel-выгрузку из Django-админки заявок: комментарии составителю трека по выбранным заявкам с разбиением на два листа (заполненные и пустые/условно пустые) и колонкой института автора.

## Requirements

### Requirement: Admin Excel export of track composer comments

Система SHALL предоставлять в Django-админке списка проектных заявок (`ProjectApplication`) действие выгрузки выбранных заявок в файл Excel (`.xlsx`).

Файл MUST содержать ровно два листа с одинаковым набором колонок в указанном порядке:

1. «Автор заявки»
2. «Институт»
3. «Название заявки»
4. «Комментарий составителю трека»

Лист «заполненные» (имя листа фиксируется реализацией, но MUST однозначно обозначать заполненные комментарии) MUST включать только заявки, у которых комментарий составителю трека считается **заполненным**.

Лист «пустые» MUST включать только заявки, у которых комментарий считается **пустым или условно пустым**.

Значения колонок MUST вычисляться так:

- «Автор заявки» — ФИО из полей заявки `author_lastname`, `author_firstname`, `author_middlename` (части через пробел; пустые части пропускаются);
- «Институт» — наименование корневого подразделения автора заявки: берётся `author.department`, поднимается по цепочке `parent` до подразделения без родителя; если автора или подразделения нет — пустая ячейка;
- «Название заявки» — `title` заявки (пусто, если не задано);
- «Комментарий составителю трека» — значение поля `track_composer_comment` заявки как есть (включая placeholder, если заявка попала на лист пустых).

Выгрузка MUST применяться к отмеченным в changelist заявкам. Если не отмечена ни одна заявка, система MUST отказать в выгрузке с понятным сообщением об ошибке.

Если среди отмеченных заявок встречаются разные семестры (более одного различных `semester_id`, включая смесь «семестр задан» и «семестр не задан»), система MUST отказать в выгрузке с понятным сообщением об ошибке.

Система MUST NOT изменять публичные API showcase и существующие Excel-выгрузки контингента института.

#### Scenario: Export splits filled and empty comments

- **WHEN** администратор отмечает заявки одного семестра, среди которых есть заявка с осмысленным комментарием и заявка с пустым комментарием, и запускает действие выгрузки
- **THEN** система возвращает xlsx-файл, где первая заявка на листе заполненных, вторая — на листе пустых, с корректными колонками автора, института, названия и комментария

#### Scenario: Placeholder comment goes to empty sheet

- **WHEN** у заявки `track_composer_comment` после нормализации совпадает с условно пустым значением (например `-`)
- **THEN** заявка попадает на лист пустых, а не заполненных

#### Scenario: Institute from root department

- **WHEN** у автора заявки `department` — дочернее подразделение с родителем без своего родителя
- **THEN** колонка «Институт» содержит наименование родительского (корневого) подразделения

#### Scenario: Mixed semesters rejected

- **WHEN** среди отмеченных заявок есть как минимум две с разными семестрами
- **THEN** система не отдаёт файл и показывает сообщение об ошибке

#### Scenario: Empty selection rejected

- **WHEN** администратор запускает действие выгрузки без отмеченных заявок
- **THEN** система не отдаёт файл и показывает сообщение об ошибке

### Requirement: Conditionally empty track composer comment classification

Система SHALL классифицировать комментарий составителю трека как **пустое или условно пустое**, если после `strip` и сравнения без учёта регистра (`casefold`) значение входит в фиксированный набор placeholder’ов, включающий как минимум:

- пустую строку;
- `-`, `—`, `–`, `.`, `…`;
- `нет`, `н/д`, `н.д.`, `n/a`, `na`;
- `нет комментария`, `без комментария`.

Иначе система SHALL классифицировать комментарий как **заполненный**.

#### Scenario: Whitespace-only is empty

- **WHEN** комментарий состоит только из пробелов
- **THEN** он классифицируется как пустой

#### Scenario: Short meaningful text is filled

- **WHEN** комментарий равен `ML` или другому тексту вне списка placeholder’ов
- **THEN** он классифицируется как заполненный
