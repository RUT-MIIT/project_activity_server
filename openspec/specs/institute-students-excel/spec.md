# institute-students-excel Specification

## Purpose

Определяет состав и источники колонок Excel-выгрузки контингента института для ответственного, включая данные заказчика и автора выбранной заявки команды.

## Requirements

### Requirement: Excel export includes customer and application author columns

Система SHALL включать в файл Excel выгрузки контингента института (`students/export`) после колонки «Проект» три дополнительные колонки: «Заказчик», «Контакты заказчика» и «Автор заявки». Значения SHALL браться из выбранной заявки команды студента (`project_application`): наименование организации-заказчика, контактные данные представителя заказчика и ФИО автора заявки (фамилия, имя, отчество через пробел; пустые части имени пропускаются).

#### Scenario: Student with selected project

- **WHEN** студент состоит в команде с выбранной заявкой, у которой заполнены заказчик, контакты и ФИО автора
- **THEN** в соответствующей строке Excel колонка «Заказчик» содержит наименование организации, «Контакты заказчика» — контакты представителя, «Автор заявки» — ФИО автора заявки

#### Scenario: Student without selected project

- **WHEN** у студента нет команды или у команды нет выбранной заявки
- **THEN** колонки «Заказчик», «Контакты заказчика» и «Автор заявки» в строке пустые

### Requirement: JSON students list contract unchanged

Система MUST NOT изменять JSON-контракт списка студентов института (`GET .../students/`) при добавлении колонок в Excel-выгрузку: ответ списка не обязан содержать поля заказчика и автора заявки.

#### Scenario: Students JSON list after export enrichment

- **WHEN** клиент запрашивает JSON-список студентов института
- **THEN** структура элементов ответа остаётся прежней относительно полей проекта (как минимум без обязательных полей заказчика и автора в `project`)
